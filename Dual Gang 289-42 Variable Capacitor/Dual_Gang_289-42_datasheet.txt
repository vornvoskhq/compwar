Dual-Gang 289-42 Variable Tuning Capacitor
Seeburg / TRW RETMA Source Code 289 Dual Air Variable Capacitor

Product Overview

The 289-42 is a vintage dual-gang air variable tuning capacitor manufactured under RETMA manufacturer code 289 (Seeburg
Corporation). Designed for broadcast radio, jukebox tuner chassis, and communications gear, it features a precision ball-bearing rear
thrust bearing assembly and stamped // C trademark symbol.
